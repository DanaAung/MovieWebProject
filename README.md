# DNA Movies — Movie Discovery & Streaming Catalog

A modern, responsive movie discovery web application built with **React** and **Vite**. Browse trending films, search across thousands of titles, and explore detailed movie overviews, ratings, and release information.

**🔗 Live Demo:** [https://danaaung.github.io/MovieWebProject/](https://danaaung.github.io/MovieWebProject/)

## Features

- **Trending & Popular Movies:** Browse curated lists of currently trending and top-rated movies.
- **Instant Search:** Real-time movie search with debounced queries for fast, responsive results.
- **Movie Details:** View high-resolution posters, release dates, ratings, genres, and full synopses.
- **Responsive Design:** Adaptive layout optimized for desktop, tablet, and mobile screens.
- **Fast Performance:** Powered by Vite for instant Hot Module Replacement (HMR) and optimized production builds.

## Tech Stack

- **Framework:** React
- **Build Tool:** Vite
- **Styling:** CSS / Tailwind CSS *(update to match your styling setup)*
- **API:** TMDB API *(or your movie data API)*
- **Linting:** ESLint

## Getting Started

### 1. Clone the Repository

    git clone https://github.com/DanaAung/MovieWebProject.git
    cd MovieWebProject

### 2. Install Dependencies

    npm install

### 3. Configure Environment Variables

Create a `.env` file in the project root and add your movie API key (e.g., TMDB):

    VITE_TMDB_API_KEY=your_api_key_here

### 4. Run the Development Server

    npm run dev

Open the local URL shown in your terminal (usually `http://localhost:5173`) to view the application.
